# عکس‌های آماده کالا

هر فایل `<key>.jpg` (مربع ۵۱۲×۵۱۲) برای همه کالاهایی نمایش داده می‌شود که نامشان (یا اگر نام چیزی نگفت، گروهشان)
با کلمه‌های زیر جور باشد. تطبیق در `MainActivity.productPhotoKeyFor()` انجام می‌شود.

کالاهایی که از آجیل ساخته شده‌اند (کره بادام زمینی، روغن گردو، ویفر، بستنی، کیک، بیسکویت، شیر بادام)
همان تصویر ساده ساخته‌شده را نشان می‌دهند.

ترتیب اولویت نمایش: عکسی که ویزیتور خودش ثبت کرده ← عکس خود کالا در آتیران (جدول ka_image، کم‌کم و فقط برای کارت‌های روی صفحه بارگیری و در حافظه گوشی نگه داشته می‌شود) ← عکس این پوشه ← تصویر ساده ساخته‌شده.
تطبیق کلمه‌ها در `MeelanoProductPhotos.keyFor()` است.

افزودن عکس تازه: فایل `<key>.jpg` را اینجا بگذارید و کلمه‌های آن را در `productPhotoKeyFor()` اضافه کنید.
عکس‌ها بدون نوشته و نشان تجاری ساخته شده‌اند تا برای همه برندها مناسب باشند.
