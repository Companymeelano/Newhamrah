# عکس‌های آماده کالا

با کلمه‌های زیر جور باشد. تطبیق در `MainActivity.productPhotoKeyFor()` انجام می‌شود.

ترتیب اولویت نمایش: عکسی که ویزیتور خودش ثبت کرده ← عکس ثبت‌شده در آتیران ← عکس این پوشه ← تصویر ساده ساخته‌شده.

افزودن عکس تازه: فایل `<key>.jpg` را اینجا بگذارید و کلمه‌های آن را در `productPhotoKeyFor()` اضافه کنید.
عکس‌ها بدون نوشته و نشان تجاری ساخته شده‌اند تا برای همه برندها مناسب باشند.
