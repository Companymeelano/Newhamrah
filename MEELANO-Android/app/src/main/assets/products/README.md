# عکس‌های آماده کالا

هر فایل `<key>.jpg` (مربع ۵۱۲×۵۱۲) برای همه کالاهایی نمایش داده می‌شود که نامشان (یا اگر نام چیزی نگفت، گروهشان)
با کلمه‌های زیر جور باشد. تطبیق در `MainActivity.productPhotoKeyFor()` انجام می‌شود.

| فایل | کلمه‌های نام کالا |
|---|---|
| pistachio.jpg | پسته |
| almond.jpg | بادام، بادوم (به‌جز بادام زمینی و بادام هندی) |
| hazelnut.jpg | فندق |
| walnut.jpg | گردو، مغز گردو |
| cashew.jpg | بادام هندی، کاجو |
| peanut.jpg | بادام زمینی |
| seeds.jpg | تخمه، تخم کدو/هندوانه/آفتابگردان، شاهدانه |
| raisin.jpg | کشمش، مویز |
| dates.jpg | خرما، رطب، مضافتی، پیارم، زاهدی، کبکاب |
| dried_fruit.jpg | برگه، انجیر، قیسی، زردآلو، آلو بخارا، توت خشک، میوه خشک |
| nuts.jpg | آجیل، مخلوط، چهارمغز، خشکبار (کلی) |

کالاهایی که از آجیل ساخته شده‌اند (کره بادام زمینی، روغن گردو، شکلات فندقی، بستنی، کیک، بیسکویت، شیر بادام)
همان تصویر ساده ساخته‌شده را نشان می‌دهند.

ترتیب اولویت نمایش: عکسی که ویزیتور خودش ثبت کرده ← عکس ثبت‌شده در آتیران ← عکس این پوشه ← تصویر ساده ساخته‌شده.

افزودن عکس تازه: فایل `<key>.jpg` را اینجا بگذارید و کلمه‌های آن را در `productPhotoKeyFor()` اضافه کنید.
عکس‌ها بدون نوشته و نشان تجاری ساخته شده‌اند تا برای همه برندها مناسب باشند.
