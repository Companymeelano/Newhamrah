# عکس‌های آماده کالا

هر فایل `<key>.jpg` (مربع ۵۱۲×۵۱۲) برای همه کالاهایی نمایش داده می‌شود که نامشان (یا اگر نام چیزی نگفت، گروهشان)
با کلمه‌های زیر جور باشد. تطبیق در `MainActivity.productPhotoKeyFor()` انجام می‌شود.

| فایل | کلمه‌های نام کالا |
|---|---|
| rice.jpg | برنج |
| cooking_oil.jpg | روغن (به‌جز روغن موتور/ترمز/بدن/بچه/مو/آرایشی) |
| black_tea.jpg | چای (به‌جز چای سبز، دمنوش، چای‌ساز، قوری، لیوان) |
| tomato_paste.jpg | رب (به‌جز رب انار/آلو/لیمو) |
| pasta.jpg | ماکارونی، پاستا |
| white_cheese.jpg | پنیر |
| mineral_water.jpg | آب معدنی، آب آشامیدنی |
| dish_soap.jpg | مایع ظرفشویی (به‌جز پودر/قرص ماشین ظرفشویی) |
| milk.jpg | شیر، شیرکاکائو، شیرموز (به‌جز شیرینی، شیر خشک، شیر برنج) |
| yogurt.jpg | ماست |

ترتیب اولویت نمایش: عکسی که ویزیتور خودش ثبت کرده ← عکس ثبت‌شده در آتیران ← عکس این پوشه ← تصویر ساده ساخته‌شده.

افزودن عکس تازه: فایل `<key>.jpg` را اینجا بگذارید و کلمه‌های آن را در `productPhotoKeyFor()` اضافه کنید.
عکس‌ها بدون نوشته و نشان تجاری ساخته شده‌اند تا برای همه برندها مناسب باشند.
