# پیشنهادهای ارتقای Meelano Visit (بعد از نسخه ۵)

## ظاهر و گرافیک
| بخش | پیشنهاد | اثر |
|---|---|---|
| همه صفحه‌ها | هماهنگ کردن رنگ‌ها با آیکون جدید (طلایی و قهوه‌ای به‌عنوان یک تم آماده «فندقی») | برنامه یک‌دست و شناخته‌شده‌تر می‌شود |
| ورود | نشان دادن اسم ویزیتور قبلی و ورود با اثر انگشت | ورود در یک لمس |
| خانه | کارت «مشتری بعدی» با دکمه تماس و مسیریابی | کار روزانه سریع‌تر شروع می‌شود |
| کالاها | عکس برای همه کالاها (۶ عکس دیگر آماده ساخت است) و نشان «پرفروش» و «کم‌موجودی» روی عکس | انتخاب کالا چشمی و سریع می‌شود |
| سبد | نوار پایین ثابت با جمع مبلغ و دکمه «ثبت پیش‌فاکتور» | اشتباه و گم شدن دکمه کمتر می‌شود |
| مشتری | کارت مشتری با مانده حساب رنگی و آخرین خرید | ویزیتور قبل از فروش وضع مشتری را می‌بیند |
| نوشته‌ها | درشت‌تر کردن نوشته‌های خیلی ریز و خواندن درست همه دکمه‌ها برای صفحه‌خوان | برای همه راحت‌تر خوانده می‌شود |

## کارکرد و نرم‌افزار
| بخش | پیشنهاد | اثر |
|---|---|---|
| انتشار | امضای ثابت نسخه نهایی (افزودن ۴ کلید امضا در تنظیمات گیت‌هاب) | نسخه‌های بعدی بدون حذف برنامه نصب می‌شوند |
| گوگل‌پلی | رساندن سطح اندروید هدف به ۳۶ | امکان انتشار در گوگل‌پلی |
| بدون اینترنت | ذخیره پیش‌فاکتور وقتی اینترنت نیست و ارسال خودکار بعد از وصل شدن | هیچ سفارشی گم نمی‌شود |
| آتیران | نشان دادن وضعیت تأیید پیش‌فاکتور (تأیید فروش، تأیید حسابداری، فاکتور شده) از خود آتیران | ویزیتور لازم نیست زنگ بزند و بپرسد |
| گزارش | گزارش روزانه با یک لمس به‌صورت PDF برای مدیر | گزارش‌دهی سریع |
| موقعیت | ثبت محل بازدید و نقشه مسیر روزانه | مدیر مسیر واقعی را می‌بیند |
| امنیت | ذخیره رمز اتصال به‌صورت رمزشده روی گوشی و خروج خودکار بعد از بیکاری | اطلاعات فروش امن‌تر می‌شود |
| سرعت | تقسیم فایل اصلی برنامه به چند بخش کوچک‌تر | خطای کمتر و ارتقای راحت‌تر |
| به‌روزرسانی | خبر دادن نسخه جدید داخل برنامه | همه ویزیتورها روی آخرین نسخه می‌مانند |

| ۶ عکس تازه کالا | ✅ شکر و قند، حبوبات، تن ماهی، پودر لباسشویی، آجیل و پسته، بیسکویت (۱۶ عکس در کل) |

| نوار ثابت پایین سبد | ✅ جمع مبلغ و دکمه قدم بعدی (افزودن کالا / انتخاب مشتری / ارسال) |

| امضای ثابت | ⏳ نیاز به افزودن ۴ کلید امضا در تنظیمات گیت‌هاب توسط صاحب مخزن |

| تقسیم فایل اصلی | 🔄 شروع شد: بخش‌های صفحه‌خوان، ساخت PDF گزارش، اشتراک فایل و انتخاب عکس کالا جدا شدند |
| خبر نسخه جدید | ✅ برنامه هر ۱۲ ساعت نسخه تازه را بررسی و خبر می‌دهد |
